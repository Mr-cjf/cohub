# 文件操作与并行纪律

此规则适用于 cohub 仓库的所有代理与子代理。

## 核心原则

1. **同一文件的写操作必须串行**：对同一个文件执行 `write` / `edit` 等写入操作时，必须先等前一次写入完成再进行下一次写入，并发写入会导致内容丢失。
2. **不同文件的只读操作可以并行**：`read` / `grep` / `glob` 等只读操作在目标文件互不相同时，可以打包在一批中同时发出，减少往返。
3. **不擅自扩大改动范围**：只改动任务明确指定的文件和代码区域，不顺手重构无关代码、不修改未被引用的文件。

## 批处理指引

| 情形 | 做法 |
|------|------|
| 读多个不同文件 | 一批发出 |
| 写同一个文件 | 串行，等前一次完成 |
| 写多个不同文件 | 可并行（文件无重叠） |
| 读写混合（写操作的目标是读操作刚读过的文件） | 先读后写，不混在同一批 |
